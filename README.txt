MINAHIL DILSHAD | BUILD. PLAY. EXPLORE.
Creative software engineering portfolio with the Little Explorer flight toy.

OPEN IT ON WINDOWS
1. Extract the entire ZIP to a folder. Do not open it from inside the ZIP.
2. Double-click index.html. It opens in your browser.
   You can also double-click Open-Portfolio.bat.

OPEN IT ON macOS OR LINUX
Extract the ZIP, then open index.html in a modern browser.
No Node.js, installation, account, or local server is needed.

LITTLE EXPLORER
Click Take a flight in the hero, or the floating astronaut further down the page.
- Move the mouse to steer.
- Hold WASD or the arrow keys to steer with the keyboard.
- Hold Space, or the Hold to boost button, for a speed boost.
- On a touchscreen, drag on the game canvas to steer.
- Fly through glowing portals to increase your score.
- Restart resets the score and flight position.
- Exit flight or Escape returns to the portfolio.

THE CURIOSITY UNIVERSE
The former About Me card is now a smiling planet with three clickable orbits.
Choose Builder, Player, or People Person to reveal a different side of Minahil.
Surprise me chooses another orbit. Click the planet for a small bounce and
sparkles, or choose the flight shortcut to launch Little Explorer.

PORTFOLIO CONTROLS
Scroll through the 3D project gallery, use its arrows or dots, or open a project
from the list below it. Each project opens a detailed panel.
The Professional Profile contains a text version of the professional background.
Pause ambient motion stops decorative motion. Browser reduced-motion settings
are respected. The game runs after you choose to launch it.

WHAT IS INCLUDED
index.html  - Portfolio content, skills, education, internships, and dialogs.
style.css   - Layout, colors, responsive styles, and decorative animation.
app.js      - Project data, project gallery, profile panels, and scroll effects.
flight.js   - Original 3D mesh character, flight controls, portals, and scoring.
Open-Portfolio.bat - Optional Windows shortcut to index.html.
README.txt  - These instructions.

The flight scene uses browser JavaScript and Canvas to render an original 3D
mesh character. It does not require Unity. The Unity section describes Minahil's
current learning interests, not a claim that this site was built in Unity.

EDITING
Use a text editor such as VS Code.
- Change biography, internships, skills, and education in index.html.
- Change project descriptions in the projects array in app.js.
- Change the design in style.css.
- Change character appearance and flight behavior in flight.js.
Save the file and refresh the browser to see your changes.

OFFLINE USE
The portfolio and flight toy work offline. Google Fonts load when the browser
has internet access; system fonts are used otherwise. GitHub and LinkedIn links
need an internet connection.

HOSTING
These are static website files. Upload index.html, style.css, app.js, and flight.js
together to your preferred static web host. Preserve the relative filenames.
The downloadable copy works independently of the hosted portfolio's access
settings. This package does not contain a database, login system, private resume,
API credentials, personal phone number, private email, or personal address.

CONTENT
Professional background follows the supplied resume and subsequent updates.
ATNI is displayed as supplied, without invented duties or dates.
Unity and game development are presented as learning interests.
Project previews are original interface studies rather than live screenshots.
